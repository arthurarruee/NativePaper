Componentes do React Native Paper usados

1. Button (botao cadastrar)
2. TextInput (nome, e-mail e senha)
3. Text (titulo)
4. Checkbox (aceite dos termos)
5. PaperProvider (App.js) 

Passos para rodar

cd TelaNative

npm install

Ajuste as versões para a versão do Expo

npx expo install --fix

Inicie o projeto:

npx expo start
